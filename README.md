# KAGE Tea — landing page de canecas fofas

Esta pasta contém uma versão editável da cópia local, remodelada como um comercial de canecas de chá fofas. A estética preserva o clima cinematográfico, escuro e japonês do site de referência, mas agora apresenta uma coleção de produtos, preços ilustrativos, benefícios, CTAs e interação de adicionar ao ritual.

## Arquivos principais

- `design-system.html` — página comercial principal.
- `assets/tea-hero.png` — imagem do hero.
- `assets/mug-sora.png` — imagem da caneca Sora.
- `assets/tea-ritual.png` — imagem da seção Ritual.
- `assets/overview/secret-pathways-assets/fonts.css` — fontes locais reaproveitadas da cópia original.

## Como abrir

Você pode abrir `design-system.html` diretamente. Se o navegador bloquear algum recurso usando `file://`, rode na pasta do projeto:

```bash
python3 -m http.server 8000
```

Depois acesse `http://localhost:8000/design-system.html`.

## Como editar

Os textos, links e produtos estão no próprio `design-system.html`. Os estilos ficam no bloco `<style>` dentro do mesmo arquivo para facilitar ajustes rápidos de cor, tipografia, espaçamento e layout.

Os preços exibidos são ilustrativos e devem ser substituídos pelos valores reais antes de publicar. O botão de compra atualmente exibe uma confirmação visual local; ele ainda não está conectado a checkout ou carrinho real.
